# fnos-cli Homepage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建采用用户选定「清爽留白」风格的 Docusaurus 单页门户。

**Architecture:** 使用 Docusaurus Classic 和 React 首页组件，关闭文档与博客。首页组件承载展示和复制交互，CSS Modules 负责局部排版，全局 CSS 负责字体和主题。

**Tech Stack:** Docusaurus、React、TypeScript、npm。

**Spec:** `docs/superpowers/specs/2026-10-29-homepage-design.md`

## Global Constraints

- 目标目录：`/Users/timandes/Projects/fnos/fnos-cli-website`；现有 CLI 项目保持不变。
- 仅中文首页；白底、蓝色强调、居中标题和浅灰代码区。
- 安装命令：`npm install -g fnos-cli`。
- GitHub：`https://github.com/Timandes/fnos-cli`；npm：`https://www.npmjs.com/package/fnos-cli`。
- 不发布、不创建后台，不引入额外单元测试框架。
- Git 分支遵循 git flow；如提交，使用英文 Conventional Commits，禁止 Co-Authored-By。

## Review Focus

- 360px 窄屏：标题、命令、导航和按钮不产生页面横向溢出。
- 剪贴板失败：显示失败反馈并允许手动选择命令。
- 无 JavaScript：主要内容、安装命令、外链仍存在于静态 HTML。
- 键盘与辅助技术：按钮有焦点样式，复制反馈可被读屏感知。
- 链接：快速开始定位安装区；外链指向真实资源，无文档或博客空入口。
